# AI模型真实训练操作指南

## 概述

本指南将帮助你实现真实的AI模型训练，用于判断街道环境情况。

## 前置要求

1. **Python 3.8+** 已安装
2. **训练数据集** 已上传到系统（通过前端"训练数据管理"上传）
3. **足够的磁盘空间**（至少5GB用于存储数据和模型）

## 训练功能说明

### AI模型能力

训练后的AI模型可以对街道图片进行5个维度的评分：

| 维度 | 说明 | 评分等级 |
|------|------|----------|
| 店招 | 评估店铺招牌的规范性和美观度 | 1-5级 |
| 行道树 | 评估街道树木的养护状况 | 1-5级 |
| 绿化 | 评估绿化覆盖率和质量 | 1-5级 |
| 人行道铺装 | 评估人行道的完好程度 | 1-5级 |
| 自行车道贯通性 | 评估自行车道的连通性 | 1-5级 |

**评分标准：**
- 1级：差
- 2级：较差
- 3级：一般
- 4级：良好
- 5级：优秀

**步骤3：启动训练服务**

双击运行：

2. 检查训练依赖
3. 准备训练数据

## 常见问题

### Q1: 安装依赖失败怎么办？

**A:** 尝试以下方法：
1. 检查网络连接
2. 使用清华镜像源：`-i https://pypi.tuna.tsinghua.edu.cn/simple`
3. 单独安装PyTorch：`pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu`

### Q2: 训练数据不够怎么办？

**A:** 系统会自动生成模拟标注。如果需要真实标注：
1. 手动编辑 `ai-models/data/annotations/annotations.json`
2. 为每张图片设置准确的评分
3. 重新运行 `prepare_training_data.py`

### Q3: 训练时间太长怎么办？

**A:** 可以调整训练参数：
1. 减少训练轮数（修改 `training_service.py` 中的 `epochs`）
2. 增加批次大小（修改 `train_model.py` 中的 `batch_size`）
3. 使用GPU加速（如果有NVIDIA显卡）

### Q4: 如何切换回模拟训练？

**A:** 修改 `training_service.py` 文件：
```python
# 将这行改为 False
TRAINING_AVAILABLE = False
```

### Q5: 训练失败怎么办？

**A:** 检查以下几点：
1. 确认训练数据已准备
2. 检查磁盘空间是否充足
3. 查看训练服务日志
4. 确认PyTorch等依赖已正确安装

## 技术细节

### 模型架构

```python
class MultiTaskStreetRatingModel(nn.Module):
    - ResNet18 骨干网络（预训练）
    - 5个独立分类器（对应5个评分维度）
    - 多任务学习架构
```

### 训练流程

1. **数据准备**：收集图片、生成标注、划分数据集
2. **模型初始化**：加载预训练ResNet18
3. **训练循环**：
   - 前向传播
   - 计算损失（5个维度的平均）
   - 反向传播
   - 更新参数
4. **验证评估**：在测试集上评估准确率
5. **模型保存**：保存最佳模型

### 数据增强

训练时使用的数据增强：
- 随机水平翻转
- 随机旋转（±10度）
- 亮度/对比度调整
- 归一化处理
