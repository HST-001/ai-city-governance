# 城市环境评分AI系统 - 小白操作指南

欢迎使用城市环境评分AI系统！本指南将帮助你快速上手，无需专业编程知识也能轻松使用。

## 一、准备工作

### 1. 检查Python是否已安装

首先，你需要确保电脑上安装了Python。请按照以下步骤检查：

1. 在键盘上同时按下 `Win + R` 键
2. 输入 `cmd` 并按回车
3. 在弹出的黑色窗口中输入 `python --version` 并按回车

如果显示Python 3.8或更高版本的信息，说明Python已安装。如果提示错误，请先安装Python 3.8+。

### 2. 下载项目文件

确保你已经有完整的项目文件，包含了`ai-models`目录。

## 二、启动AI服务

### 一键启动服务

1. 找到项目中的 `ai-models` 文件夹
2. 双击运行 `start_service.py` 文件（Windows系统）
   或者：
   - 在键盘上同时按下 `Shift + 右键`
   - 选择 "在此处打开PowerShell窗口"
   - 输入 `python start_service.py` 并按回车

启动脚本会自动：
- 检查Python环境
- 创建虚拟环境（首次运行）
- 安装所需依赖
- 启动API服务

### 等待服务启动

服务启动后，会在窗口中显示如下信息：
```
 * Serving Flask app 'api_server'
 * Debug mode: off
 * Running on all addresses (0.0.0.0)
 * Running on http://127.0.0.1:5000
 * Running on http://你的IP地址:5000
```

此时，AI服务已经成功运行，不要关闭这个窗口！

## 三、使用AI评分功能

### 1. 方法一：使用简单的测试脚本（推荐小白）

我们可以创建一个简单的测试脚本来上传图片并查看结果：

1. 在 `ai-models` 目录下新建一个文本文件，命名为 `test_predict.py`
2. 将以下代码复制粘贴进去：

```python
import requests
import json
import os

# API服务地址
url = 'http://localhost:5000/api/v1/predict'

# 要测试的图片路径
# 请将下面的路径修改为你自己的图片路径
image_path = 'C:/Users/hy/Desktop/AI Coding Learning/AI+城市治理/photo/梨园路.jpg'

# 检查文件是否存在
if not os.path.exists(image_path):
    print(f"错误：找不到图片文件 {image_path}")
    print("请修改代码中的图片路径为正确的路径")
    exit()

# 上传文件并预测
try:
    with open(image_path, 'rb') as f:
        files = {'file': f}
        response = requests.post(url, files=files)
    
    # 解析结果
    result = response.json()
    
    # 打印评分结果
    if result['status'] == 'success':
        data = result['data']
        print("\n===== 评分结果 =====")
        print(f"店招评分: {data['ratings']['store_sign']}分 ({data['ratings_text']['store_sign']})")
        print(f"行道树评分: {data['ratings']['street_trees']}分 ({data['ratings_text']['street_trees']})")
        print(f"绿化评分: {data['ratings']['greening']}分 ({data['ratings_text']['greening']})")
        print(f"人行道铺装评分: {data['ratings']['sidewalk_paving']}分 ({data['ratings_text']['sidewalk_paving']})")
        print(f"自行车道贯通性评分: {data['ratings']['bike_lane_connectivity']}分 ({data['ratings_text']['bike_lane_connectivity']})")
        print(f"综合评分: {data['overall_rating']}分 ({data['overall_rating_text']})")
        
        print("\n===== 处理建议 =====")
        print(data['suggestion'])
    else:
        print(f"预测失败: {result['message']}")
        
 except Exception as e:
    print(f"发生错误: {e}")
    print("请确保API服务正在运行，并且图片路径正确")
```

3. 修改代码中的图片路径，指向你想评分的图片
4. 运行测试脚本：在PowerShell窗口中输入 `python test_predict.py` 并按回车
5. 查看评分结果和处理建议

### 2. 方法二：使用训练脚本训练自己的模型

如果你想训练自己的模型，需要准备带标注的数据集：

1. 在 `ai-models/data` 目录下创建训练数据文件夹
2. 在PowerShell窗口中运行：
   ```
   cd scripts
   python train_model.py --data_path ../data/your_dataset --epochs 10
   ```

## 四、查看评分详情

评分等级说明：
- 1分：差
- 2分：较差  
- 3分：一般
- 4分：良好
- 5分：优秀

系统会根据各项评分提供综合建议，指导后续的城市环境改善工作。

## 五、常见问题解答

### 1. 服务启动失败怎么办？

- 检查Python是否正确安装
- 确保有足够的磁盘空间
- 关闭防火墙或允许Python访问网络

### 2. 预测结果不准确怎么办？

- 确保图片清晰，包含完整的街道场景
- 可以通过训练更多数据来提高准确性
- 调整拍摄角度，确保目标物体完整可见

### 3. 如何关闭服务？

在启动服务的窗口中，按 `Ctrl + C` 组合键即可关闭服务。

## 六、注意事项

1. 首次运行会自动安装依赖，可能需要一些时间，请耐心等待
2. 服务占用端口5000，请确保该端口未被其他程序占用
3. 大型图片处理可能需要一定时间，请耐心等待结果
4. 如遇问题，可以重新启动服务尝试解决
