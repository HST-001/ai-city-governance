# AI模型真实训练 - 详细操作步骤

## 前置检查

在开始之前，请确认：
- [ ] Python 3.8+ 已安装
- [ ] 已通过前端上传了训练数据集
- [ ] 磁盘空间至少有5GB
- [ ] 网络连接正常（用于下载依赖）

---

## 详细操作步骤

### 步骤1：打开命令行

**操作：**
1. 按 `Win + R` 键
2. 输入 `cmd` 并回车
3. 输入以下命令进入ai-models目录：

```bash
cd "c:\Users\hy\Desktop\AI Coding Learning\AI+城市治理\ai-models"
```

**成功提示：**
```
C:\Users\hy\Desktop\AI Coding Learning\AI+城市治理\ai-models>
```

**如果失败：**
- 提示"找不到路径"：请检查路径是否正确
- 提示"拒绝访问"：请以管理员身份运行命令行

---

### 步骤2：检查Python版本

**操作：**
输入以下命令并回车：

```bash
python --version
```

**成功提示：**
```
Python 3.8.0
```
或
```
Python 3.9.7
```
或
```
Python 3.10.x
```

**如果失败：**
```
'python' 不是内部或外部命令
```
**解决方法：** 请先安装Python 3.8+

---

### 步骤3：检查pip是否可用

**操作：**
输入以下命令并回车：

```bash
pip --version
```

**成功提示：**
```
pip 21.0.1
```
或
```
pip 23.x.x
```

**如果失败：**
```
'pip' 不是内部或外部命令
```
**解决方法：** 重新安装Python，确保勾选"Add Python to PATH"

---

### 步骤4：安装PyTorch（核心依赖）

**操作：**
输入以下命令并回车（可能需要5-10分钟）：

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

**成功提示：**
```
Successfully installed torch-2.0.1 torchvision-0.15.2 ...
```

**中间过程提示（正常）：**
```
Collecting torch
  Downloading torch-2.0.1-cp310-cp310-win_amd64.whl (200.0 MB)
Installing collected packages: torch, torchvision
```

**如果失败：**
```
ERROR: Could not find a version that satisfies the requirement torch
```
**解决方法：** 尝试使用清华源：
```bash
pip install torch torchvision -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 步骤13：在前端创建训练任务

**操作：**
1. 打开浏览器，访问：`http://localhost:5173`
2. 登录系统
3. 点击左侧菜单"图片训练与评级"
4. 点击"创建训练任务"按钮

**成功提示：**
弹出"创建训练任务"对话框，包含以下字段：
- 任务名称（必填）
- 任务描述（选填）
- 模型类型（必填）
- 训练数据集（必填，下拉选择）

**如果失败：**
- 页面无法打开：检查前端服务是否运行
- 没有训练数据集选项：检查是否上传了训练数据集

---

### 步骤14：填写训练任务信息

4. **训练数据集**：选择已上传的数据集（如"绿化养护_覆盖率_07e1116c"）

所有字段都填写完整，"创建"按钮可以点击

## 常见问题排查

### 问题1：安装依赖时网络超时

**症状：**
```
ReadTimeoutError: HTTPSConnectionPool ...
```

**解决方法：**
1. 使用清华镜像源（已在命令中包含）
2. 如果仍然超时，尝试多次运行安装命令
3. 检查网络连接

---

### 问题2：训练数据准备失败

**症状：**
```
没有找到训练图片，请先上传训练数据集
```

**解决方法：**
1. 打开前端"训练数据管理"页面
2. 点击"上传数据集"
3. 选择图片文件并上传
4. 等待上传完成
5. 重新运行步骤10

---

### 问题3：训练服务启动失败

**症状：**
```
ModuleNotFoundError: No module named 'xxx'
```

**解决方法：**
1. 查看缺失的模块名（xxx）
2. 单独安装该模块：
   ```bash
   pip install xxx -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```
3. 重新运行步骤11

---

### 问题4：训练进度一直卡住

**症状：**
进度条长时间不更新（超过10分钟）

**解决方法：**
1. 检查训练服务日志是否有错误
2. 按 `Ctrl+C` 停止训练服务
3. 重新启动训练服务
4. 重新创建训练任务

---

### 问题5：训练失败

**症状：**
任务状态变为"失败"

**解决方法：**
1. 查看训练服务日志中的错误信息
2. 检查磁盘空间是否充足
3. 检查训练数据是否有效
4. 重新运行步骤10准备数据
5. 重新创建训练任务
