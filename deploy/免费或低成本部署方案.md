## 完全免费方案

### 方案1: Oracle Cloud Free Tier ⭐⭐⭐⭐⭐

**优势：**
- ✅ 永久免费
- ✅ 配置不错（2核1GB ARM + 200GB存储）
- ✅ 带宽充足
- ✅ 支持Docker

**限制：**
- ARM架构（需要重新构建镜像）
- 需要绑定信用卡验证

**申请步骤：**
1. 访问 https://www.oracle.com/cloud/free/
2. 注册账号（需要邮箱验证）
3. 绑定信用卡（不会扣费）
4. 创建Always Free实例
5. 选择操作系统：Ubuntu 20.04 ARM

**部署步骤：**
```bash
# 连接到服务器
ssh ubuntu@服务器公网IP

# 安装Docker（ARM版本）
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh

# 上传项目文件
# 使用SCP或Git克隆项目

# 修改docker-compose.yml
# 由于是ARM架构，需要确保镜像支持ARM

# 启动服务
docker-compose up -d
```

**注意事项：**
- 需要修改Dockerfile以支持ARM架构
- 内存只有1GB，可能需要优化配置

## 内网穿透方案（需要您的电脑在线）

### 方案8: ngrok ⭐⭐⭐⭐

**优势：**
- ✅ 免费版可用
- ✅ 配置简单
- ✅ HTTPS支持

**限制：**
- 免费版域名随机
- 连接数有限制
- 需要您的电脑在线

**使用步骤：**

1. 注册ngrok账号：https://ngrok.com
2. 下载ngrok客户端
3. 运行以下命令：

```bash
# 将本地80端口映射到公网
ngrok http 80
```

4. 复制显示的公网URL，例如：`https://abc123.ngrok.io`
5. 将这个URL发送给HR

**免费版限制：**
- 随机域名
- 每次启动域名会变
- 每月40GB流量
- 每秒40个连接

**付费版：**
- $5/月起
- 固定域名
- 更多流量和连接

### 方案10: frp（需要自己的服务器）

**优势：**
- ✅ 完全开源免费
- ✅ 功能强大
- ✅ 性能好

**限制：**
- 需要有一台公网服务器
- 配置相对复杂

**使用步骤：**

1. 在公网服务器上运行frps（服务端）
2. 在您的电脑上运行frpc（客户端）
3. 配置端口映射

**配置示例：**

frps.ini（服务端）：
```ini
[common]
bind_port = 7000
vhost_http_port = 80
```

frpc.ini（客户端）：
```ini
[common]
server_addr = 公网服务器IP
server_port = 7000

[web]
type = http
local_port = 80
custom_domains = yourdomain.com
```

lt --port 80 --subdomain your-app-name

## 快速开始指南

### Oracle Cloud部署（推荐）

1. **注册账号**
   - 访问 https://www.oracle.com/cloud/free/
   - 注册并绑定信用卡

2. **创建实例**
   - 选择"Always Free"套餐

3. **部署应用**
   ```bash
   # 连接到服务器

   # 安装Docker
   curl -fsSL https://get.docker.com -o get-docker.sh
   sh get-docker.sh

   # 克隆项目
   git clone https://github.com/your-username/ai-city-governance.git
   cd ai-city-governance

   # 启动服务
   docker-compose up -d
   ```

4. **访问系统**
   - 打开浏览器访问：http://服务器公网IP
