# 街道更新维护治理系统

基于AI视觉分析技术的城市街道设施智能评估与管理系统，支持店招、行道树、绿化、人行道铺装、自行车道贯通性等多维度分析评估。

## 项目架构

- **前端**: React + TypeScript + Ant Design
- **后端**: Spring Boot微服务架构
- **数据存储**: PostgreSQL + Redis + MinIO分布式存储
- **AI模型**: 基于PyTorch框架开发

## 核心功能

1. **照片上传与管理**: 支持批量上传、位置标注和元数据管理
2. **AI视觉分析**: 自动识别街道设施并进行等级评估
3. **综合评分系统**: 基于多维度评估结果生成综合评分
4. **地图可视化**: 直观展示街道设施分布和评估结果
5. **报告生成**: 自动生成评估报告和维护建议
