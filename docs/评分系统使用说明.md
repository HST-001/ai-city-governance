# 城市治理照片评分系统使用说明

## 1. 系统概述

城市治理照片评分系统是一款基于AI技术的城市环境评估工具，能够对上传的城市环境照片进行多维度评分，并提供针对性的改进建议。系统通过分析照片中的环境要素，如道路状况、绿化率、公共设施完整性、卫生状况等，为城市管理者提供客观、量化的环境质量评估数据。

## 2. 核心功能模块

### 2.1 照片评分功能

- **单张照片评分**：上传单张城市环境照片后，系统自动分析并给出多维度评分
- **批量照片评分**：支持多张照片同时评分，适用于大规模环境评估场景
- **高级分析模式**：可针对特定维度进行深度分析，获取更详细的评估结果

### 2.2 评分历史管理

- **评分记录查看**：查看所有历史评分记录，支持按时间、评分、维度等筛选
- **评分详情查看**：查看单条评分记录的详细信息，包括各维度得分和分析说明
- **评分数据导出**：支持将评分历史数据导出为Excel或CSV格式，便于进一步分析

### 2.3 评分对比分析

- **照片对比**：选择两张或多张照片进行评分对比，直观展示差异
- **维度对比**：针对特定维度对比不同照片的评分情况
- **趋势分析**：分析同一地点不同时期的评分变化趋势，评估环境改善效果

### 2.4 评分系统设置

- **评分维度配置**：管理评分维度及其权重设置
- **评分标准调整**：调整各维度的评分标准和阈值
- **系统参数设置**：配置批量处理限制、分析深度等系统参数

## 3. 使用指南

### 3.1 单张照片评分

1. 导航至「照片上传」页面
2. 选择一张城市环境照片上传
3. 在弹出的评分选项中，可选择启用高级分析或指定关注维度
4. 点击「评分」按钮，系统开始分析并显示评分结果
5. 查看总体评分和各维度详情，系统会同时生成改进建议

### 3.2 批量照片评分

1. 导航至「照片上传」页面
2. 点击「批量上传」选项，选择多张照片或文件夹
3. 选择批量处理模式（同步/异步）
4. 点击「开始评分」按钮，等待处理完成
5. 处理完成后可查看批量评分结果汇总

### 3.3 查看评分历史

1. 导航至「评分管理」→「评分历史记录」页面
2. 使用筛选条件（日期范围、评分范围、问题维度等）缩小查询范围
3. 在列表中可直接查看评分概况，点击「详情」可查看完整评分报告
4. 使用「导出数据」功能可将当前筛选结果导出为Excel文件

### 3.4 进行照片评分对比

1. 导航至「评分管理」→「评分对比分析」页面
2. 在照片选择区域，搜索并选择需要对比的照片（最多4张）
3. 点击「开始对比分析」按钮
4. 在对比结果页面，可查看总体评分对比和维度详情对比
5. 通过标签页切换不同的对比视图

### 3.5 配置评分系统

1. 导航至「评分管理」→「评分系统设置」页面
2. 调整系统评分参数，如满分分数、批量处理限制等
3. 管理评分维度，包括启用/禁用维度、调整权重等
4. 点击「保存设置」按钮应用更改

## 4. 评分维度说明

系统对城市环境照片的评分包括以下主要维度：

- **道路状况**：评估道路平整程度、标识完整性、交通设施状况
- **绿化率**：评估区域内植被覆盖比例和绿化质量
- **公共设施**：评估公共座椅、垃圾桶、照明等设施的完整性和可用性
- **卫生状况**：评估区域清洁度、垃圾处理情况
- **空间秩序**：评估区域规划合理性、车辆停放秩序等
- **建筑外观**：评估建筑物外观维护状况、美观度

## 5. 常见问题解答

### 5.1 评分结果不准确怎么办？

- 确保照片光线充足、画面清晰，能够完整展示评估区域
- 可尝试启用高级分析模式获取更精确的结果
- 对同一区域多角度拍摄，取平均评分结果

### 5.2 如何提高批量评分效率？

- 对于大量照片，建议使用异步批量处理模式
- 确保服务器资源充足，可调整系统参数优化处理速度
- 考虑将照片按区域分组进行批量处理

### 5.3 评分历史数据可以保留多久？

系统默认保留所有评分历史数据，管理员可根据存储需求设置数据保留策略。
