# 城市治理照片评分系统 - 使用说明文档

## 1. 系统概述

城市治理照片评分系统是一个基于AI技术的综合平台，用于自动评估城市环境照片，生成多维度评分和改进建议。系统集成了照片上传、AI分析、地图可视化、历史记录管理等功能，为城市管理部门提供数据支持和决策依据。

### 1.1 系统架构

- **前端**：React + TypeScript + Ant Design
- **后端**：Spring Boot + Spring MVC + Spring Data JPA
- **数据库**：MySQL
- **AI模型**：TensorFlow/PyTorch
- **地图服务**：高德地图 API

### 1.2 核心功能模块

- **照片上传与管理**：支持批量上传、预览、删除等操作
- **AI评分系统**：自动分析照片并生成多维度评分
- **地图可视化**：在地图上展示评分结果的空间分布
- **评分历史管理**：查询、筛选、导出历史评分记录
- **评分对比分析**：比较不同照片的评分差异
- **评分系统设置**：自定义评分维度、权重等参数

## 2. 系统部署

### 2.1 环境要求

- **Java**：JDK 1.8 或更高版本
- **Node.js**：v14.0 或更高版本
- **MySQL**：8.0 或更高版本
- **Maven**：3.6 或更高版本
- **npm/yarn**：最新稳定版

### 2.2 后端部署

1. 克隆项目仓库
2. 导入数据库脚本：`/backend/src/main/resources/init.sql`
3. 配置数据库连接：修改 `application.properties` 中的数据库配置
4. 编译打包：`mvn clean package`
5. 启动应用：`java -jar target/urban-governance-rating.jar`

### 2.3 前端部署

1. 进入前端目录：`cd frontend`
2. 安装依赖：`npm install` 或 `yarn install`
3. 配置API地址：修改 `.env` 文件中的 `REACT_APP_API_BASE_URL`
4. 开发模式启动：`npm start`
5. 生产环境构建：`npm run build`
6. 部署构建产物：将 `build` 目录部署到Web服务器

## 3. 用户使用指南

### 3.1 登录与注册

系统提供标准的用户认证流程：
- **注册**：填写用户名、密码、邮箱等基本信息
- **登录**：使用用户名和密码登录系统
- **找回密码**：通过邮箱验证找回密码

### 3.2 照片上传与管理

1. 导航至「照片管理」页面
2. 点击「上传照片」按钮，选择本地照片文件
3. 填写照片基本信息（如位置、描述等）
4. 可批量上传多张照片
5. 在照片列表中可进行预览、编辑、删除等操作

### 3.3 AI评分生成

1. 在照片管理页面，选择一张或多张照片
2. 点击「请求评分」按钮
3. 系统将自动处理并生成评分结果
4. 处理完成后，可查看详细评分报告

### 3.4 评分维度说明

系统从以下维度对城市环境进行评分（满分5分）：

| 维度名称 | 权重 | 评分标准 |
|---------|------|--------|
| 道路状况 | 20% | 道路平整程度、标识清晰度、交通秩序等 |
| 绿化率 | 15% | 绿植覆盖率、养护状况、景观设计等 |
| 公共设施 | 20% | 设施完整性、可用性、维护状况等 |
| 卫生状况 | 20% | 清洁度、垃圾处理、环境整洁度等 |
| 空间秩序 | 15% | 车辆停放、商业秩序、公共空间利用等 |
| 建筑外观 | 10% | 建筑风貌、标识规范、美观程度等 |

### 3.5 地图可视化查看

1. 导航至「地图视图」页面
2. 地图上会显示带有评分的照片标记
3. 点击标记可查看照片预览和简要评分信息
4. 可使用筛选条件按评分范围、时间等过滤显示

### 3.6 评分历史记录管理

1. 导航至「评分历史记录」页面
2. 系统默认显示最近的评分记录列表
3. 使用筛选条件（如日期范围、评分范围、问题维度等）进行精准查询
4. 支持按不同字段排序
5. 点击「查看详情」可查看完整评分报告
6. 可导出评分数据为Excel或CSV格式

### 3.7 评分对比分析

1. 导航至「评分对比分析」页面
2. 输入两张照片的ID或通过搜索选择
3. 点击「对比分析」按钮
4. 系统将显示两张照片在各维度的评分对比图表
5. 突出显示差异最大的维度和总体评分对比

### 3.8 评分系统设置

1. 导航至「评分系统设置」页面（管理员权限）
2. 可配置评分标准参数
3. 自定义评分维度及其权重
4. 设置系统处理参数（如批量处理限制）
5. 启用/禁用高级分析功能

## 4. 常见问题解答

### 4.1 评分结果异常

**问题**：评分结果明显不符合实际情况怎么办？

**解决方案**：
- 检查照片质量是否清晰
- 确保照片内容完整包含待评估场景
- 可联系管理员进行人工审核和修正

### 4.2 系统性能问题

**问题**：上传大量照片时系统响应缓慢

**解决方案**：
- 建议每次批量上传不超过20张照片
- 等待系统处理完成后再进行后续操作
- 避开系统高峰时段进行大批量操作

### 4.3 数据导出失败

**问题**：无法导出评分历史数据

**解决方案**：
- 检查筛选条件是否过于宽泛，减少数据量
- 使用更精确的时间范围进行筛选
- 确认浏览器允许文件下载

### 4.4 地图显示问题

**问题**：地图上看不到评分标记

**解决方案**：
- 检查是否有评分数据
- 调整地图缩放级别和查看范围
- 确认筛选条件是否过于严格
